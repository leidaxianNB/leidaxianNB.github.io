博客接入Waline评论系统

Created2026-10-18|Updated2026-10-18|博客
|Post Views:|Comments:

前言

博客开了这么久一直没评论区，访客想留言都没地方说，这次顺手把它接了。

选型没纠结多久：Butterfly 主题本身就支持一堆评论系统，挑了个免费、读者不用注册、还带管理后台的，最后选了 Waline。

Waline 需要后端，用 Vercel 免费部署，数据存 LeanCloud 国际版（不用备案）。

部署 Waline

Vercel 部署

我是照着 B 站教程部署的：BV1J2XuBtEGn

Waline 需要一个数据库来存评论，部署向导里会要求配置存储。官方一键部署默认是 LeanCloud（AppID、AppKey、MasterKey 那套），不过教程里用的是别的方案，跟着视频填就行，我这里没用 LeanCloud。

部署完会得到一个 xxx.vercel.app 地址，我的叫 blogwaline-azure.vercel.app。

到这里后端就好了，Vercel 控制台显示 Ready。

问题1：vercel.app 打不开

部署是成功的，但浏览器打开 xxx.vercel.app 直接超时，连不上。老问题了，vercel.app 在国内基本处于被墙的状态。

那就绑自定义域名，我的域名是 cloudns.ch 的，DNS 托管在 Cloudflare。

问题2：Vercel 域名验证走不通

在 Vercel 的 Domains 里加上 comment.leidaxiannb.cloudns.ch 之后，它要求加两条记录：

CNAME 好办，问题出在 TXT。Vercel 提示 TXT 要加在 _vercel.cloudns.ch，这是 cloudns.ch 的父域，属于 CloudNS 的地盘，自己的 zone 里根本加不了，验证直接卡死。

cloudns.ch 这类免费子域在 Vercel 的域名验证上就是这么尴尬。

解决：Cloudflare Worker 反代

验证走不通，那就不绑域名了，用 Cloudflare Worker 把 comment.leidaxiannb.cloudns.ch 转发到 vercel.app，效果一样，顺带解决了国内访问。

问题3：后台登录 failed to fetch

评论区倒是正常的，文章页能加载评论框、能发评论，但管理后台 /ui/ 一直注册不了，报 failed to fetch。

F12 打开 Network 一看，后台页面的请求全部指向 https://blogwaline-azure.vercel.app/... 而不是自定义域名，连过去就是超时。

清浏览器缓存没用，无痕窗口也一样，基本确定不是浏览器的问题。

原因：Waline 服务器按它收到的请求域名生成后台页面的 API 地址。Worker 转发时把主机名换成了 vercel.app，所以后台页面里的 API 地址也变成了 vercel.app。

解决：Worker v2 重写 HTML

思路：Worker 转发返回的 HTML 时，把里面的 blogwaline-azure.vercel.app 全部替换成 comment.leidaxiannb.cloudns.ch，后台页面以为 API 就在同域，请求自然走 Worker 代理。

注意替换后要删掉 content-length 和 content-encoding 响应头，不然内容长度对不上。

重新部署 Worker 后，后台注册成功，登录正常。

顺带踩的坑：hexo-front-matter

部署的时候还遇到一个怪问题，hexo generate 报 YAML 错误，提示 unidentified alias “*IDE**：JetBrains”。

排查半天发现是 hexo-front-matter 的锅：它有个”新格式”逻辑，会把文件里第一个 --- 之前的内容当 YAML 配置解析。有一篇文章正文里用了 --- 做分隔线，前面的正文就被当成 YAML 了。

解决：文章开头老老实实写标准的 front matter（--- title date tags ---），正文里的 --- 就都是普通 Markdown 了。

结果

评论区上线：

文章底部有评论区，读者填昵称邮箱就能评论
首页和文章页显示评论数
管理后台可以审核、删评论

整体体验不错，读者不用注册，管理也方便。教程里用的免费存储加上 Vercel 免费额度，对个人博客来说完全够用。

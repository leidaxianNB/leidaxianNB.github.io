杀戮尖塔2 模组开发笔记 —— 自定义卡牌

1. 环境准备

1.1 开发工具

  • IDE：JetBrains Rider 或 Visual Studio（推荐 Rider，对 Godot 支持较好）。
  • 引擎：Godot 4.x（.NET 版本），用于编辑资源和打包 .pck。
  • SDK：.NET 9.0（与游戏版本匹配，查看游戏目录下的 Sts2.runtimeconfig.json）。
  • 游戏：杀戮尖塔2（Steam 版），确保能正常启动。

2.1 定义卡牌类

新建 C# 文件，继承 CardModel，并放在合适的命名空间（推荐 YourMod.Cards）。

必需成员：

  • **CanonicalVars**：定义卡牌的动态变量（伤害、格挡、力量层数等），使用 List<DynamicVar>。
  • 构造函数：指定费用、类型、稀有度、目标。
  • **OnPlay**：打出时的异步逻辑（造成伤害、施加能力、抽牌等）。
  • **OnUpgrade**（可选）：升级时修改 CanonicalVars 中的数值。

3. 关键易错点（避坑指南）

常见错误 原因 解决方案
无法解析符号 'CardModel' 缺少 using MegaCrit.Sts2.Core.Models.Cards; 或未引用游戏 DLL。 添加 using 并检查项目引用。
没有要重写的合适方法 基类中没有该方法，或方法签名（参数）不匹配。 查阅官方示例或反编译确认正确的方法名（如 AfterCardDrawn 有 bool fromHandDraw 参数）。
ValueProp 找不到 缺少 using MegaCrit.Sts2.Core.ValueProps;。 添加该 using。
ThrowingPlayerChoiceContext 找不到 缺少 using MegaCrit.Sts2.Core.GameActions.Multiplayer;。 添加该 using。
动态变量升级无效 OnUpgrade 中未正确调用 UpgradeValueBy，或访问了错误的变量名。 使用属性访问（如 DynamicVars.Damage）或索引访问（DynamicVars["Damage"]），确保名称一致。
卡牌不显示在百科/卡池 本地化文件缺失、图片路径错误、未注册到正确卡池、模组未启用。 检查 cards.json、图片路径、注册代码，重启游戏或开新档。
Buff 不触发 事件回调方法名错误、条件判断不通过、未调用 Flash() 或未正确传递 Amount。 对照官方 SpeedsterPower 或 DemonFormPower 检查方法签名和条件。
图片不显示 .tres 内部路径指向错误图片、图片格式/尺寸异常、文件名大小写不一致。 用文本编辑器检查 .tres 中的 path，确保指向正确的 PNG，且与卡池文件夹匹配。
PowerCmd.Apply 报类型转换错误 目标/来源参数不是 Creature 类型。 使用 base.Owner.Creature（玩家）或 base.Creature（怪物自身）代替 this。
base.DynamicVars["Key"] 与 .Key 混淆 属性访问（.Strength）和索引访问（["StrengthPower"]）键名不同。 检查 CanonicalVars 中定义的泛型类型名，使用对应的访问方式。

4. 测试与调试技巧

  • 控制台命令（需启用 DevConsole Mod）：
    • 获取卡牌：card <卡牌ID>
    • 测试 Buff：power <BuffID> <层数> <目标索引>（0 为玩家）
  • 日志输出：使用 Log.Info("消息") 在控制台打印调试信息。
  • 断点调试：Rider 支持附加到 Godot 进程，可对 Mod 代码断点调试。

5. 常用命令速查

6. 总结：制作一张卡牌的完整流程

  1. 编码：创建 CardModel 子类，定义动态变量、构造函数、OnPlay 和 OnUpgrade。
  2. 本地化：在 cards.json 添加标题与描述。
  3. 图片：准备 PNG 和对应的 .tres 文件（放在正确的卡池目录）。
  4. 注册：在 ModInitializer 中添加到卡池。
  5. 测试：编译打包，进入游戏验证。
